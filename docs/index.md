# Mensal

**Todas as contas, um só rumo.**

O Mensal é um app para Android que organiza as contas do mês: receitas e despesas que se repetem todo mês, compras
parceladas, impostos anuais como IPVA e IPTU, faturas de cartão de crédito e gastos pagos aos poucos, como o mercado.
Você vê, mês a mês, quanto entra, quanto sai e o que já foi pago.

Seus dados ficam só no seu celular: o Mensal não tem conta de usuário, não envia seus dados para nenhum servidor e
não tem anúncios.
